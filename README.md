# ParcelPilot AI Support Agent

An internal operations chatbot built with Streamlit, Gemini 3.6 Flash, LangChain, FAISS and Excel.

## Features
- PDF policy retrieval (RAG)
- Order lookup
- Account lookup
- Ticket lookup
- Escalation workflow

## Sample Queries
- What is the cancellation policy?
- ORD-1001
- ACCT-001
- TKT-501
- ESCALATE TKT-501

# ParcelPilot AI

AI-powered Internal Operations Support Chatbot built with Streamlit, Gemini 3.6 Flash, LangChain and FAISS.

## Features
- PDF policy retrieval (RAG)
- Order lookup
- Account lookup
- Ticket lookup
- Escalation workflow

## Tech Stack
- Streamlit
- Gemini 3.6 Flash
- LangChain
- FAISS
- Pandas
